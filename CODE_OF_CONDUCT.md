# Code of Conduct

SlowQuitApps welcomes participation from people with different backgrounds and
levels of experience. Everyone taking part in project spaces is expected to
help keep them respectful and constructive.

## Expected behavior

- Be considerate and respectful in discussions and reviews.
- Give useful, specific feedback about the work rather than attacking people.
- Accept that people may disagree, and discuss disagreements calmly.
- Respect people's privacy. Do not publish private information without consent.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Insults, demeaning comments, or repeated unwanted contact.
- Publishing another person's private information without consent.
- Disruptive conduct that prevents others from participating.

## Scope and enforcement

This code applies in the repository, its issue tracker, pull requests, and
project-related public spaces. Project maintainers may remove content, close
discussions, or restrict participation when behavior violates this code.

To report a concern, contact the project maintainer privately using the contact
information on the maintainer's GitHub profile. Please do not post sensitive
details in a public issue.
